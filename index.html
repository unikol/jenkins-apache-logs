📌 Task Goal

The goal was to create a Jenkins Pipeline that installs Apache2/httpd on a remote Linux VM, verifies the operating system, starts the web server, checks HTTP availability, and reads web server logs to detect 4xx and 5xx HTTP errors.

Main requirement The deployment pipeline had to be saved as a Jenkinsfile, uploaded to GitHub, and executed in Jenkins by retrieving the pipeline from the repository.

📜 Final Jenkinsfile

This Jenkinsfile contains the complete pipeline logic: checkout, SSH test, Apache deployment, HTTP verification, and access log analysis. 

pipeline {
    agent any

    parameters {
        string(name: 'TARGET_HOST', defaultValue: '192.168.56.102', description: 'Target Linux VM IP address')
    }

    stages {
        stage('Checkout') {
            steps {
                checkout scm
                echo 'Repository was checked out successfully.'
            }
        }

        stage('Prepare deployment scripts') {
            steps {
                writeFile file: 'deploy_apache.sh', text: '''#!/usr/bin/env bash
set -euo pipefail

cat /etc/os-release

if command -v apt-get >/dev/null 2>&1; then
    WEB_SERVICE="apache2"
    sudo apt-get update -y
    sudo DEBIAN_FRONTEND=noninteractive apt-get install -y apache2
elif command -v dnf >/dev/null 2>&1; then
    WEB_SERVICE="httpd"
    sudo dnf install -y httpd
elif command -v yum >/dev/null 2>&1; then
    WEB_SERVICE="httpd"
    sudo yum install -y httpd
else
    echo "Unsupported Linux distribution."
    exit 1
fi

sudo systemctl enable "$WEB_SERVICE"
sudo systemctl restart "$WEB_SERVICE"
echo "<h1>Deployed by Jenkins Pipeline</h1><p>Apache/httpd installation completed successfully.</p>" | sudo tee /var/www/html/index.html >/dev/null
sudo systemctl status "$WEB_SERVICE" --no-pager
curl -I http://localhost
'''

                writeFile file: 'check_logs.sh', text: '''#!/usr/bin/env bash
set -euo pipefail

if [ -f /var/log/apache2/access.log ]; then
    LOG_FILE="/var/log/apache2/access.log"
elif [ -f /var/log/httpd/access_log ]; then
    LOG_FILE="/var/log/httpd/access_log"
else
    echo "No Apache/httpd access log file found."
    exit 2
fi

sudo tail -20 "$LOG_FILE"
ERROR_LINES=$(sudo awk '$9 ~ /^[45][0-9][0-9]$/ {print}' "$LOG_FILE" || true)

if [ -n "$ERROR_LINES" ]; then
    echo "$ERROR_LINES"
    exit 1
else
    echo "No 4xx or 5xx errors found in the access log."
    exit 0
fi
'''
            }
        }

        stage('Test SSH connection') {
            steps {
                withCredentials([sshUserPrivateKey(credentialsId: 'jenkins-apache-ssh-key', keyFileVariable: 'SSH_KEY_FILE', usernameVariable: 'SSH_USER')]) {
                    bat """
                        for /f "delims=" %%U in ('whoami') do set "CURRENT_USER=%%U"
                        icacls "%SSH_KEY_FILE%" /inheritance:r
                        icacls "%SSH_KEY_FILE%" /grant:r "%CURRENT_USER%:R"
                        ssh -i "%SSH_KEY_FILE%" -o StrictHostKeyChecking=no -o UserKnownHostsFile=NUL -o IdentitiesOnly=yes -o BatchMode=yes %SSH_USER%@${params.TARGET_HOST} "hostname && whoami && sudo -n whoami"
                    """
                }
            }
        }

        stage('Install and start Apache/httpd') {
            steps {
                withCredentials([sshUserPrivateKey(credentialsId: 'jenkins-apache-ssh-key', keyFileVariable: 'SSH_KEY_FILE', usernameVariable: 'SSH_USER')]) {
                    bat """
                        for /f "delims=" %%U in ('whoami') do set "CURRENT_USER=%%U"
                        icacls "%SSH_KEY_FILE%" /inheritance:r
                        icacls "%SSH_KEY_FILE%" /grant:r "%CURRENT_USER%:R"
                        scp -i "%SSH_KEY_FILE%" -o StrictHostKeyChecking=no -o UserKnownHostsFile=NUL -o IdentitiesOnly=yes -o BatchMode=yes deploy_apache.sh %SSH_USER%@${params.TARGET_HOST}:/tmp/jenkins_deploy_apache.sh
                        ssh -i "%SSH_KEY_FILE%" -o StrictHostKeyChecking=no -o UserKnownHostsFile=NUL -o IdentitiesOnly=yes -o BatchMode=yes %SSH_USER%@${params.TARGET_HOST} "tr -d '\\r' < /tmp/jenkins_deploy_apache.sh > /tmp/jenkins_deploy_apache_fixed.sh && sudo bash /tmp/jenkins_deploy_apache_fixed.sh"
                    """
                }
            }
        }

        stage('Check web server logs for 4xx and 5xx') {
            steps {
                script {
                    def logCheckStatus = 0
                    withCredentials([sshUserPrivateKey(credentialsId: 'jenkins-apache-ssh-key', keyFileVariable: 'SSH_KEY_FILE', usernameVariable: 'SSH_USER')]) {
                        logCheckStatus = bat(script: """
                            for /f "delims=" %%U in ('whoami') do set "CURRENT_USER=%%U"
                            icacls "%SSH_KEY_FILE%" /inheritance:r
                            icacls "%SSH_KEY_FILE%" /grant:r "%CURRENT_USER%:R"
                            scp -i "%SSH_KEY_FILE%" -o StrictHostKeyChecking=no -o UserKnownHostsFile=NUL -o IdentitiesOnly=yes -o BatchMode=yes check_logs.sh %SSH_USER%@${params.TARGET_HOST}:/tmp/jenkins_check_logs.sh
                            ssh -i "%SSH_KEY_FILE%" -o StrictHostKeyChecking=no -o UserKnownHostsFile=NUL -o IdentitiesOnly=yes -o BatchMode=yes %SSH_USER%@${params.TARGET_HOST} "tr -d '\\r' < /tmp/jenkins_check_logs.sh > /tmp/jenkins_check_logs_fixed.sh && sudo bash /tmp/jenkins_check_logs_fixed.sh"
                        """, returnStatus: true)
                    }

                    if (logCheckStatus == 1) {
                        currentBuild.result = 'UNSTABLE'
                    } else if (logCheckStatus != 0) {
                        error "Unexpected error during log verification. Exit code: ${logCheckStatus}"
                    } else {
                        echo 'Log verification completed successfully. No 4xx/5xx errors found.'
                    }
                }
            }
        }
    }
}

🧠 Main Issues Solved

During this task, several real Jenkins and SSH-related problems appeared. Each issue was analyzed, fixed, and documented as part of the final solution.

1. Empty TARGET_HOST

Problem Jenkins tried to connect to nick@ without the VM IP address. 
nick@ "hostname && whoami && sudo -n whoami"
Fix The Jenkinsfile was changed to use ${params.TARGET_HOST} directly.

2. Windows SSH key permissions

Problem Windows OpenSSH rejected the Jenkins temporary private key because file permissions were too open. 
WARNING: UNPROTECTED PRIVATE KEY FILE!
Fix The pipeline updates private key permissions with icacls. 
icacls "%SSH_KEY_FILE%" /inheritance:r
icacls "%SSH_KEY_FILE%" /grant:r "%CURRENT_USER%:R"

3. Invalid SSH key format

Problem Jenkins reported that the SSH key had an invalid format. 
Load key "ssh-key-SSH_KEY_FILE": invalid format
Fix The correct OpenSSH private key was added to Jenkins Credentials. 
BEGIN OPENSSH PRIVATE KEY
Private key content
END OPENSSH PRIVATE KEY

4. Groovy dollar escaping issue

Problem Jenkinsfile parsing failed because Groovy interpreted the $ symbol inside a shell command. 
illegal string body character after dollar sign
Fix Instead of using sed -i 's/\r$//', the pipeline used tr -d '\r' to remove Windows CRLF characters before executing scripts on Linux. 
tr -d '\r' < /tmp/jenkins_deploy_apache.sh > /tmp/jenkins_deploy_apache_fixed.sh
